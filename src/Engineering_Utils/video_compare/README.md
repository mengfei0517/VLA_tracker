# Video Compare

Compare 1–4 videos side by side. Set a sync time per video, choose playback speed (up to 16x), then play one or all.

- **Source:** paste a video URL or choose a local file.
- **Layout:** 1 = full width, 2 = 50/50, 3 = thirds, 4 = 2×2 grid.

Open `index.html` in a browser. For URL-based videos, serve over HTTP (e.g. `python3 -m http.server 8080`) if you hit CORS issues.
